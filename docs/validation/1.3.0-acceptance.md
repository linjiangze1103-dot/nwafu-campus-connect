- 使用用户级隐藏后台，不引入系统服务；控制核心独立于窗口消息循环。
- 在现有专用仓库的功能分支实施，没有另建工作树；保留按阶段提交及本地执行记录。
- 网卡事件与每秒快照用于唤醒，学校 HTTPS 状态为认证判断依据；快照中的网关不是完整的最佳路由表。
- 无相同条件的旧版基准，不报告未经测量的速度提升倍数。
- 保留旧版文件及升级备份。安装回滚已有组件测试，本机验证的是正常迁移；没有对真实账号环境注入磁盘故障或强制断网。
