# 西农校园网助手

适配西北农林科技大学校园网的非官方 Windows 工具。提供加密保存账号、后台自动认证、断网重试和开机自启。认证引擎使用未修改的 [BitSrunLoginGo v1.6.8](https://github.com/Mmx233/BitSrunLoginGo)。

## 使用

1. 从本仓库 Releases 下载 Windows x64 压缩包，全部解压到固定目录。
2. 连接学校 Wi-Fi 或校园网线，打开 `西农校园网助手.exe`，填写网页认证账号密码，点击“保存并启动”。
3. 点击“开启自启”，设置登录 Windows 后自动运行。
4. 如需提前启动，运行同目录的 `Enable-FastStartup.ps1`，创建无额外延迟的当前用户登录任务。网络仍需先由 Windows 连好。

关闭窗口后继续后台运行，无托盘。再次打开软件显示现有窗口；点击“停止自动连接”才停止检测，不注销当前网络。“关闭自启”只影响以后登录，不停止当前连接；快速启动器同样遵守这个开关。

## 连接策略

- 入口：`https://portal.nwafu.edu.cn`，`ac_id=1`，无账号后缀。
- 网络故障初期按 3、3、5、5、10 秒间隔重试，持续故障逐步退避至 10 分钟；网络变化通知会提前触发检测。
- 密码错误、设备上限等认证拒绝会暂停重试，需处理后手动恢复。
- 正常在线每 60 秒检测一次；接口在线状态不等于所有外网服务均可访问。

## 隐私与本地数据

账号密码仅用于学校认证，由 Windows DPAPI 按当前用户加密，保存在 `%LOCALAPPDATA%\NWAFU-CampusConnect`，不应随软件分享。引擎认证期间会短暂生成受目录权限保护的明文临时配置，完成或取消后删除，下次启动也会清理残留。诊断日志不记录账号、密码或原始认证响应；快速启动日志可能包含本地安装路径，分享前请检查。

## 构建

在 Windows x64 上使用系统 .NET Framework C# 编译器，无需安装 Python 或 Go：

```powershell
.\Build.ps1 -OutputDirectory .\build
```

从上游官方 Release 获取 `bitsrun_windows_amd64.tar.gz`，将其中 `bitsrun.exe` 放入 `build/engine/`。

引擎 SHA256：`509e8842167a479a563f24d154d9d4536b2541b46f1231d13ee37a51a1107785`。

使用 `scripts/Prepare-Release.ps1` 可下载并校验固定版本引擎，生成可分享 ZIP，附上引擎对应源码。完整的手工构建命令见该脚本。

## 验证与当前限制

已有核心策略、DPAPI 存储、150% DPI 布局、启动停止、关闭窗口保持后台、隐藏窗口模拟认证及网络恢复通知测试。运行 `tests/Run-Tests.ps1`、`Run-LayoutTests.ps1`、`Run-UiTests.ps1`、`Run-HiddenTests.ps1`。

界面测试会短暂调整当前用户的本软件自启项并在 finally 中恢复，请在个人测试环境运行。隐藏认证测试使用模拟接口，不会向学校提交测试账号。

目前发布为测试版本：本机已观察到无需打开界面自动联网；快速启动任务能启动进程并避免重复实例。真实冷启动后的联网耗时、不同宿舍与账号类型的兼容性仍需验证，不承诺“开机即联网”或完全没有 bug。自启发生在登录 Windows 后。
