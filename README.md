# 西农校园网助手 1.3.0（候选测试版）

适配西北农林科技大学校园网的非官方 Windows x64 工具。账号使用学校网页认证账号；认证引擎为未修改的 BitSrunLoginGo v1.6.8。此版本完成后台架构改造，真实重启后的五秒目标仍需验收。

## 使用

1. 全部解压 ZIP，双击“安装或更新.exe”。程序安装到当前用户的固定目录，无需管理员权限。直接打开包中的主程序也会进入安装；已有同版本时直接打开已安装程序。
2. 打开“西农校园网助手.exe”，输入账号密码，保存并启动。可从固定目录创建桌面快捷方式。
3. 在界面开启自启，会自动注册当前用户登录后的快速任务，并保留普通自启回退；无需另运行脚本。
4. 关闭窗口后后台继续工作，无托盘；再次打开显示同一界面。点击停止才停止自动连接，暂停状态跨重启保留。关闭自启只影响未来登录。

稳定目录：%LOCALAPPDATA%\Programs\NWAFU-CampusConnect。账号数据仍在 %LOCALAPPDATA%\NWAFU-CampusConnect，升级保留凭据与暂停意愿。手动安装后显示界面，静默升级继续在后台运行。安装失败会尝试回滚；旧版本备份保留在同级 backup 目录。

## 本次变化

后台连接核心独立于窗口和 UI 定时器，自启不加载界面资源。网络变化唤醒检测，睡眠恢复立即检测；认证请求有总截止时间，避免长期卡住。入口探测和认证使用一致的直连路径，不修改系统代理；重复事件不会并发认证。

正常在线每 60 秒检查；初始恢复采用短间隔，持续失败逐步退避。明确密码错误或设备限制暂停；不确定结果先查询状态，避免响应丢失导致重复认证。

“校园网已认证”与“已验证外网连通”分别显示。启动、恢复和手动检测时会访问百度、腾讯的固定 HTTPS robots.txt 端点验证外网，不发送账号或认证令牌；站点失败不会触发已在线账号反复登录。

## 隐私与诊断

账号密码由 Windows 当前用户 DPAPI 加密。认证期间会生成受目录权限保护的短暂明文配置，完成、取消或下次启动清理。不要分享数据目录。

新日志 diagnostic-v2.log 包含版本、运行 ID、阶段和耗时，不记录账号、密码、IP、令牌或原始响应。磁盘写入失败时保留内存诊断；界面“复制诊断”可导出。Collect-StartupEvidence.ps1 生成当前启动的脱敏汇总；缺少可靠登录或网卡就绪时间时标记证据不足，不声称五秒达标。

## 构建与验证

使用 Windows 自带 .NET Framework C# 编译器：

~~~powershell
.\Build.ps1
.\tests\\Run-Tests.ps1
.\tests\\Run-FastConnectTests.ps1
.\tests\\Run-LayoutTests.ps1
.\scripts\\Prepare-Release.ps1
~~~

新测试使用模拟传输和隔离数据，不向学校发送测试账号，也不修改真实自启项。布局测试需要桌面环境。构建脚本需 Windows PowerShell 5.1 或更新版，运行程序不依赖 PowerShell。

五秒验收从“已经登录且校园接口地址与路由就绪”开始计算，包含应用启动延迟。必须完成至少三次重启、两次恢复及一次真实需要认证的样本；当前候选包不保证不同电脑或学校服务器异常时也在五秒内完成。
